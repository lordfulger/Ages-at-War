# Ages at War

A side-view battle game through ten ages, from the Stone Age to the far future, for 1 to 4 players on one phone or online across phones.

**Play:** https://lordfulger.github.io/Ages-at-War/

- **iPhone:** open the link in Safari, tap Share, then Add to Home Screen.
- **Android:** open the link in Chrome, tap ⋮, then Add to Home screen or Install app.

To play together online, one player taps **Online → Host an online game** and shares the 5-letter room code; the others tap **Online**, type the code and tap **Join**.
